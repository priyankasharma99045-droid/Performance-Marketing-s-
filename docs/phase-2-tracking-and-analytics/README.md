# Phase 2: Tracking and analytics

**Weeks 3–4** · 10 lessons, 1 weekly review, 1 checkpoint

## What you'll be able to do

- Explain how tags, cookies, and click IDs carry data from a browser into reports.
- Build consistent UTM links and campaign names.
- Find answers in GA4 reports and build a funnel exploration.
- Publish a web page, and track page views, clicks, and leads with GTM and GA4.
- Plan how conversions reach Google Ads and Meta, including the Conversions API and offline
  sales.
- Set up Consent Mode, and explain how consent and attribution change the numbers.

## Before you start

You need a GitHub account for lesson 15. The [setup guide](../00-start-here/setup.md) lists
every account and when you need it.

## Week 3 review

**Saturday** · 30–45 minutes · **Save to:** `my-work/notes/week-03-review.md`, using
[`templates/weekly-review.md`](../../templates/weekly-review.md)

Answer from memory first, then check against the lessons.

1. Explain, step by step, how a page view on a website ends up in a GA4 report.
2. What's the difference between a first-party and a third-party cookie?
3. Write a complete UTM link for a Meta retargeting ad, following your naming standard.
4. Name the four kinds of GA4 events, with one example each.
5. What's the difference between a dimension and a metric? Give two of each.
6. In your practice 14 funnel, which step lost the most people, and what would you test?
7. Is your landing page live and showing in GA4 Realtime? If not, fix it today. Lesson 16
   builds on it.

Then catch up on any unfinished practice from the week.
