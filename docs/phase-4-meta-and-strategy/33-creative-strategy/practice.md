# Practice 33: Write hooks and three ad concepts

**30 minutes** · **You need:** Your personas and offer, and an AI chatbot (optional) · **Save to:** `my-work/notes/lesson-33.md`

## Goal

Write five hooks and three distinct ad concepts for your practice business, one of them drafted
with AI and then edited by you.

## Steps

1. **Hooks:** Write 5 hooks, each under 10 words. Use a different angle for each one. At least 2
   must use your customers' own words from practice 6.
2. **Concepts:** Write 3 ad concepts, each with a different angle and format:

   | Field | Concept 1 | Concept 2 | Concept 3 |
   |---|---|---|---|
   | Angle | | | |
   | Format and ratio | | | |
   | Hook | | | |
   | Visual, or second-by-second script | | | |
   | Primary text (about 125 characters) | | | |
   | Headline | | | |
   | CTA button | | | |
   | Persona it targets | | | |

3. **AI draft:** For concept 3, ask an AI chatbot to draft it. Give it your persona, offer, and
   angle. In your notes, record:
   - The prompt you used
   - What it produced
   - What you changed, and why
   - Any claims you had to remove or check
4. **Sound-off check:** For each video concept, describe what someone sees in the first 2
   seconds with the sound off.

## Done when

- [ ] 5 hooks are written, each with a different angle.
- [ ] 3 concepts are complete, with different angles and formats.
- [ ] The AI draft, your edits, and any removed claims are documented.
- [ ] Every video concept passes the sound-off check.

## Check yourself

1. Why test different angles instead of different background colors?

   <details><summary>Answer</summary>

   Different angles reach different motivations and can change results a lot. Small visual
   tweaks rarely do, and they give Meta little creative variety to work with.
   </details>

2. An AI tool writes "Rated #1 coffee by 10,000 customers." What do you do?

   <details><summary>Answer</summary>

   Remove it unless you can prove it. AI invents claims, and false claims break advertising
   rules and mislead customers.
   </details>

3. Why supply a 9:16 version of every ad?

   <details><summary>Answer</summary>

   Reels and Stories are full-screen vertical placements. A square or horizontal ad there
   wastes space and looks out of place.
   </details>
